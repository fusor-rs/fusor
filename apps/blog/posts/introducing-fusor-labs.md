Fusor started as one idea: write an interface as ordinary HTML, and keep every decision in
Rust. A month later, it is a small lab. We make tools, then we use them.

The idea behind Fusor Labs is simple. We ship fast applications written in Rust, as many as we
can, and each one exists because it solves a real problem someone has. They are not tech demos.

We also want to bring the latest work in AI, compilers, databases and WebAssembly to every
device: browsers, terminals, phones and desktops.

Two things guide us. Using what we make should take one CLI command that does everything, with
no tutorial needed to get it running. And everything stays open source.

Here is what we have so far.

## The tools

- **fusor**, the web framework, released on September 23.
- **HyperCMD**, which lays the same HTML out in a terminal, released on October 3.
- **hyperpane**, which runs a fusor app as an iPhone, iPad and Mac app. It is still in
  development.

## The things

The tools are only worth what they make. [SQL Bomb](https://boom.fusor.build/) is a terminal
SQL client built with HyperCMD, released on October 5. Hughie, a private cloud for your family
with AI that runs at home, opened its [waitlist](https://hughie.si/) on October 16.

### And a few for fun

spotify-tui and supabase-tui are hobby projects, built to see how far HTML in a terminal can
go. They live on [Made with fusor](/made-with-fusor).
