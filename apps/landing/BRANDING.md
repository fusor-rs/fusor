# fusor identity

The mark is a two-piece F: an upper and a lower shape.

The editable masters are [the symbol](public/brand/fusor.svg) and
[the outlined wordmark](public/brand/fusor-wordmark.svg). The symbol contains two
filled paths; the wordmark contains five. All logo SVGs contain vector paths,
with no embedded raster images, external fonts, or scripts.

Use the symbol alone for small icons and avatars. The avatar files have opaque
backgrounds and enough clear space for a circular crop. X recommends 400×400
pixels and accepts PNG files up to 2 MB; use the 400px PNG directly when uploading.
See [X's profile-photo guidance](https://help.x.com/en/managing-your-account/common-issues-when-uploading-profile-photo).

| Role | Color |
| --- | --- |
| Upper shape | Vermilion `#DF5036` |
| Lower shape and interface accent | Oxide `#A83228` |
| Light background and reversed artwork | Warm white `#FAF9F6` |
| Wordmark and monochrome artwork | Charcoal `#272A2C` |

Preserve the proportions, spacing between the two shapes, and clear space.
Use the reversed artwork on dark backgrounds. The badge uses a transparent
cutout rather than painting the symbol in an assumed background color.
